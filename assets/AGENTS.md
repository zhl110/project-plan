## 通用工作纪律（初始种子，后续由 agent 与用户共同优化）

1. 不写说明性文字，只保留直接执行准则。
2. 改动前先读相关文档与既有规则，不重复造轮子。
3. 长任务每阶段向用户汇报进度，不静默长跑。
4. 每阶段完成必验证。
5. 删除知识块 / 文件前先通读全文，确认无价值再删。
6. 遇到不确定，先问最关键的一个问题，再动手。
7. 规则只留当前生效：更新规则直接改 / 删旧条文，不保留旧版标注、不写变更原因（进度流水照常记录，不在此限）。
